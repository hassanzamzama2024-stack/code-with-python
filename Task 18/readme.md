 Build a simple Guess the Number Game using the Python concepts you have learned so far.

Requirements

1. Display a welcome message for the game.
2. Generate a secret number between 1 and 100.
3. Ask the user to guess the number.
4. Use a while loop to continue asking until the correct number is guessed.
5. Use if, elif, and else statements to display:
   - Too High! Try Again.
   - Too Low! Try Again.
   - Congratulations! You guessed the correct number.
6. Count and display the total number of attempts taken by the user.
7. Store every guessed number in a list.
8. Display all guessed numbers after the game ends.
9. Display:
   - First Guess
   - Last Guess
   - Total Number of Guesses
10. Ask the user whether they want to play again.
11. If the user chooses Yes, restart the game.
12. If the user chooses No, display a thank-you message and end the program.
