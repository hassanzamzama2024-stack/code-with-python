Objective:
Build a simple Student Grading System using if, elif, and else statements while practicing lists, dictionaries, string operations, and basic calculations.

Task Requirements:

1️⃣ Take input for:

* Student Name
* Registration Number
* Physics Marks
* Chemistry Marks
* Mathematics Marks

2️⃣ Store the subject marks in a list.

3️⃣ Calculate and display:

* Total Marks
* Average Marks
* Percentage

4️⃣ Assign a grade based on the percentage:

* 90% and above → A+
* 80% to 89% → A
* 70% to 79% → B
* 60% to 69% → C
* 50% to 59% → D
* Below 50% → F

5️⃣ Apply the following string operations on the student name:

* Convert to UPPERCASE
* Convert to lowercase
* Convert to Title Case
* Display the length of the name

6️⃣ Store the complete student record in a dictionary.

7️⃣ Display a well-formatted Result Card showing:

* Registration Number
* Student Name
* Subject Marks
* Total Marks
* Average Marks
* Percentage
* Grade

Instructions:

* Use if, elif, and else statements.
* Use meaningful variable names.
* Write clean and properly indented code.
* Format the output neatly.
* Test your program with different marks before submission.s
