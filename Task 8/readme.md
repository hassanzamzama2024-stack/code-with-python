Student Result Management 
Deadline: Today

Objective: Store student information and calculate academic results.

1. Take input for:

   * Student Name
   * Subject 1 Marks
   * Subject 2 Marks
   * Subject 3 Marks
   * Subject 4 Marks
   * Subject 5 Marks
2. Store all marks in a list.
3. Display the complete marks list.
4. Calculate and display:

   * Total Marks
   * Average Marks
   * Percentage
5. Display:

   * Highest Marks
   * Lowest Marks
6. Apply string operations on the student name:

   * Convert to uppercase
   * Convert to lowercase
   * Display name length
7. Display all information in a formatted report.
