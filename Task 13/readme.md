Objective: Practice creating, updating, and accessing data using dictionaries.

1. Take input for:

   * Student Name
   * Physics Marks
   * Chemistry Marks
   * Mathematics Marks
2. Store the information in a dictionary.
3. Display the complete dictionary.
4. Display the student's name.
5. Display the marks of each subject separately.
6. Calculate and display:

   * Total Marks
   * Average Marks
   * Percentage
7. Update the marks of any one subject.
8. Add a new field *Grade* with any value.
9. Remove the *Grade* field.
10. Display all dictionary keys.
11. Display all dictionary values.
12. Display the final updated dictionary.
